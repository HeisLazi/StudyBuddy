# StudyBuddy

StudyBuddy is a focused study system that turns learning material into structured subject data, reviewable tests, and restrained character progression.

## Public V2 status

This repository is the new public V2. The complete original MVP remains private while useful systems are audited, simplified, and deliberately ported.

The focused core is:

```text
PDF or study material → validated subject JSON → study/test session → character progression
```

Large legacy worlds, unfinished experiments, and unrelated game systems are not automatically part of V2.

## Contribution model

Work is issue-driven, acceptance-tested, and independently reviewed. Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing changes and use the supplied issue and pull-request templates.

Generated learning content must be reviewable by the user. Do not expose private source, credentials, personal study material, or paid/licensed content.
